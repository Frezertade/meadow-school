# Meadow School

Private family home-education app for Pennsylvania — **web + iOS** (Expo Router).

Ages **3–7** first: play-based literacy, early math, drawing/art, and an always-present lesson-grounded tutor named **Meadow**.

## Run

```bash
npm install
npm run web      # browser
npm run ios      # Xcode simulator / device
npm start       # Expo chooser
```

## What’s in v1

- Age bands: Little Meadow (3–4), Kindergarten Path (5), Grade 1 Trail (6–7)
- Lesson player with teach blocks + reading / math / drawing exercises
- Meadow help button on every lesson (grounded + safety-filtered; works offline)
- Parent PIN desk: rename kids, set age band, PA statute checklist
- Local progress per child

## Legal note

This app helps you teach and document. It does **not** replace filing a Pennsylvania home-education affidavit with your district (e.g. Donegal SD) when compulsory attendance applies.
